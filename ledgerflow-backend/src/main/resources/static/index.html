OBSERVER ET COMPRENDRE

Le parcours des données.

Un événement n’est pas traité dès qu’il est publié. On suit chaque étape.

Comment lire ce flux ?

API + journal

Enregistre l’opération et son événement dans une même transaction.

→
Outbox + Kafka

Transmet l’événement, avec de nouvelles tentatives si nécessaire.

→
Réception analytique

Vérifie et enregistre chaque événement une seule fois.

→
Spark + BI

Calcule puis publie les statistiques de la journée.

Derniers calculs Spark

Un calcul relancé ne double pas les statistiques.
Un retard temporaire n’est pas nécessairement une perte. La QA rapproche les identifiants, les montants, les devises et les soldes, pas seulement les compteurs.
