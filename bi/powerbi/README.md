# LedgerFlow — rapport Power BI

Ouvrir **LedgerFlow.pbip** avec Power BI Desktop, saisir les identifiants du
compte PostgreSQL de lecture seule, puis cliquer **Actualiser**.

Les instructions et limites de validation sont dans
[le guide Power BI](../../docs/power-bi.md).

Le dossier `.Report` contient les deux pages et treize visuels.
Le dossier `.SemanticModel` contient les tables, paramètres PostgreSQL et mesures.
Les mots de passe et les données importées ne sont pas versionnés.
